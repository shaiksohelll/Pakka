# Pakka

> Production-grade open-source escrow infrastructure for Indian marketplaces.

A reference implementation of milestone-based escrow built for two-sided service marketplaces. Atomic Postgres state machine, RLS-enforced data isolation, realtime sync, PWA + Play Store delivery.

**🚧 Demo Mode:** All money is simulated. Real INR escrow requires an RBI-approved PPI license — see [`/docs/production-swap.md`](./docs/production-swap.md) for the Razorpay Route integration path.
